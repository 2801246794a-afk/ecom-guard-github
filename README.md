# 电商运营把关台

一个无需后端、可以直接部署到 GitHub Pages 的静态小工具，适合做商品发布前的快速自查：

- 商品标题 / 主图 / 详情页 / 直播话术的高风险表达提示
- 区分 P0 高风险表达、P1 资质核验、P2 材质证据提醒
- 用供应商 / 项目口径和检测报告状态控制提示边界
- 按售价、成本、物流、平台费、投放、达人佣金和退货率估算单均利润
- 自动计算建议保本售价
- 所有数据仅在浏览器本地计算，不上传服务器

## 本地运行

这是纯 HTML / CSS / JavaScript 项目，不需要安装依赖。直接双击 `index.html` 即可预览；也可以在项目目录运行：

```bash
python -m http.server 8080
```

然后打开 <http://localhost:8080>。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个空仓库。
2. 将本目录中的全部文件上传到仓库根目录。
3. 在仓库的 Settings → Pages 中选择 Source 为 Deploy from a branch。
4. 选择 `main` 分支和 `/ (root)` 目录，保存后等待部署完成。

此版本使用 GitHub Pages 内置的分支部署，无需自定义工作流。

## 使用边界

风险扫描是规则型自查，不是法律意见；平台规则、费率和实际售后成本会变化，发布前应以商家后台、对应货号资料和检测报告为准。尤其是羊绒类商品：没有对应检测报告时，不要把供应商口径扩写成“100%”“纯羊绒”或具体成分百分比。
